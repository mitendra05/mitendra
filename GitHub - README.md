## 🏗️ What I've built

Most of my professional work lives in private company repositories. Here is what's behind them.

### Axipays — payment gateway, built from scratch
I owned the build from March 2023 and led the team that took it to production **in three months**.

- **Card processing:** 3DS and non-3DS flows across server-to-server, hosted page and iFrame integrations
- **Acquirer integrations:** CyberSource (Visa), Mastercard Payment Gateway Services (MPGS) and Redsys (Spain)
- **Scalability and reliability:** concurrent processing with goroutines behind a load balancer, Redis caching, duplicate-charge prevention, and a polling service that resolves pending transactions so gateway and bank state stay consistent
- **Risk and fraud:** device fingerprinting, risk rules, whitelists and blacklists, and a **merchant URL tracing** system I designed and built myself to catch merchants processing on undeclared websites
- **Dynamic Currency Conversion** so cardholders pay in their home currency
- **Money movement back office:** automated refunds and settlements, and a **bank reconciliation engine** I designed and built myself
- **Infrastructure:** AWS, Cloudflare, and CI/CD with GitHub Actions
- **Portals:** website, admin, merchant and referral portals
